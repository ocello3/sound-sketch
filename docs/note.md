# Command
S.bottでサーバー起動
S.quitでサーバー停止
Cmd + dでhelpを表示
shift Cmd dでhelpをpop up
shift Cmd iでソースコードを表示

# 線形変換
| メソッド | 用途 | よく使う度 |
| --- | --- | --- |
| linlin | 線形→線形 |  |
| linexp | 線形→指数 | 周波数への変換で使う |
| explin | 指数→線形 | 周波数からの逆変換 |
| expexp | 指数→指数 |  |
| lincurve | カーブ付き線形変換 | easingっぽい |
| curvelin | カーブ→線形 |  |
| curvelin / lincurve | イージングのような変換 |  |
